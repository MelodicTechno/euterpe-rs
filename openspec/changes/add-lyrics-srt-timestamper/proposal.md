# Proposal

## Why

给歌曲做歌词字幕（SRT）通常要借助 Aegisub 这类专业工具，导入音频、对齐波形、逐段输入时间码，门槛高且打断听歌的节奏。我们希望提供一个极简的桌面工具：导入歌曲与纯文本歌词，一边播放一边按空格给每行歌词打上开始/结束时间，最后直接导出可用的 SRT 文件。

## What Changes

- 从零搭建一个 Tauri 2 + React + TypeScript + Tailwind CSS 的桌面应用（Windows 优先），具备可运行的开发与打包流程。
- 新增「导入」能力：支持拖拽文件到窗口或通过文件选择器导入音频（mp3/wav）与歌词文本（txt），拖入新文件时替换当前会话内容。
- 新增「播放控制」能力：播放/暂停（P 键与界面按钮）、进度条拖动跳转、实时播放进度与时间显示；歌曲播完自动停止，不循环。
- 新增「歌词打点」能力：空格键第一次按下记录当前行开始时间，第二次按下记录结束时间并自动切到下一行；O 键回滚到上一次打点/修改之前的状态；支持在界面上手动微调任意行的开始/结束时间。
- 新增「歌词预览」能力：预览模式下歌词随播放进度滚动，当前行高亮，形似主流流媒体音乐软件的歌词视图。
- 新增「SRT 导出」能力：把已完成打点的歌词转换为标准 SRT，校验时间顺序与合法性，并通过保存对话框导出为 `.srt` 文件。
- 应用为纯本地工具，不上传音视频或歌词，不引入账号与网络依赖。

## Capabilities

### New Capabilities

- `media-import`: 导入并替换音频与歌词文本文件，解析歌词为按行划分的时间轴条目。
- `playback-control`: 音频播放、暂停、跳转、播放结束处理，以及快捷键驱动的传输控制。
- `lyric-timing`: 空格打点流程、行状态推进、O 键回滚与逐行时间手动微调。
- `lyric-preview`: 随播放滚动的歌词预览视图与当前行高亮。
- `srt-export`: 把打点结果序列化为标准 SRT 并保存到本地文件系统。

## Impact

- 新增应用脚手架与构建配置：`package.json`、Vite、TypeScript、Tailwind、`src-tauri/`（Rust + Tauri 配置）。
- 新增前端模块：媒体导入、音频播放器封装、打点状态机、SRT 序列化、预览视图。
- 新增 Tauri 依赖：对话框与文件系统插件（保存 SRT、选择导入文件）；无后端服务与数据库。
- 新增单元测试范围：SRT 时间格式化与序列化、打点状态机、歌词文本解析。
- 目标平台：Windows 优先，架构上保持 Tauri 跨平台可移植性，但本期不针对 macOS/Linux 做验证。
