# Spec Delta

## Purpose

定义歌词视窗的滚动跟随与滚动条呈现，让用户在编辑与预览歌词时始终看清当前行，同时避免无关的横向滚动和突兀的滚动条破坏界面。

## ADDED Requirements

### Requirement: 编辑模式当前行自动居中

编辑模式的歌词列表在当前行发生变化时，MUST 将该行滚动到可视区域中央附近。当前行变化包括打点推进、O 键回滚以及用户点击选择某一行。

#### Scenario: 打点推进后当前行居中

- **WHEN** 用户完成一行打点，当前行推进到下一行
- **THEN** 歌词列表自动把新的当前行滚动到可视区域中央附近

#### Scenario: 回滚后当前行居中

- **WHEN** 用户按下 O 键回滚，当前行回到被回滚的那一行
- **THEN** 歌词列表自动把该行滚动到可视区域中央附近

#### Scenario: 点击选择行后居中

- **WHEN** 用户点击歌词列表中的某一行使其成为当前行
- **THEN** 该行被滚动到可视区域中央附近

#### Scenario: 用户手动滚动后保持位置

- **WHEN** 当前行未变化，用户手动滚动歌词列表
- **THEN** 列表停留在用户滚动到的位置，不被立即拉回；直到当前行再次变化时才重新居中

### Requirement: 歌词视窗禁止横向滚动

歌词视窗 MUST NOT 出现横向滚动条，也不得产生横向滚动。在应用可用窗口宽度内，歌词文本与时间编辑控件 MUST 通过换行、截断或重排保持在可视区域内，不得因横向溢出而被裁切到无法阅读或编辑。

#### Scenario: 超长歌词行

- **WHEN** 某行歌词包含一段没有空格的超长文本
- **THEN** 歌词视窗不出现横向滚动条，文本在可视宽度内换行或截断显示

#### Scenario: 窗口较窄时的编辑控件

- **WHEN** 窗口宽度收窄到时间编辑控件无法与歌词并排显示
- **THEN** 行内容重排，开始/结束时间控件仍可操作，且歌词视窗不出现横向滚动条

### Requirement: 纵向滚动条融入背景

歌词视窗的纵向滚动条 MUST 采用与深色背景同色系的弱化配色，其滑块在轨道上仍可辨认并可拖动。纵向滚动条 MUST 仅在内容超出可视区域时出现。

#### Scenario: 内容超出时可拖动

- **WHEN** 歌词行数超出可视区域
- **THEN** 右侧出现纵向滚动条，滑块颜色与背景接近但仍可辨认，用户可拖动滑块滚动歌词

#### Scenario: 内容未超出时不显示

- **WHEN** 歌词行数未超出可视区域
- **THEN** 歌词视窗不显示纵向滚动条
