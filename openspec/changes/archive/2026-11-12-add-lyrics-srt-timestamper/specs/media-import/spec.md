# Spec Delta

## Purpose

让用户把音频与纯文本歌词带入应用，并在需要时替换当前会话内容，为后续的歌词打点和字幕导出提供输入。

## ADDED Requirements

### Requirement: 导入音频文件

用户 SHALL 能通过把文件拖入窗口或使用文件选择器导入音频，支持格式为 mp3 与 wav。导入成功后该音频成为当前音轨，界面显示文件名与总时长。

#### Scenario: 拖拽导入音频

- **WHEN** 用户把一个 mp3 或 wav 文件拖入窗口
- **THEN** 应用把该文件设为当前音轨，显示文件名与总时长，并让播放器进入可播放状态

#### Scenario: 通过文件选择器导入音频

- **WHEN** 用户点击导入音频并选择一个 mp3 或 wav 文件
- **THEN** 应用执行与拖拽导入相同的加载行为

#### Scenario: 导入不支持的音频格式

- **WHEN** 用户拖入或选择一个非 mp3/wav 的文件作为音频
- **THEN** 应用显示不支持该格式的错误提示，并保持当前音轨不变

### Requirement: 导入歌词文本

用户 SHALL 能导入 UTF-8 编码的纯文本歌词。应用按换行拆分歌词，非空行按原始顺序各生成一条待打点歌词，空行被忽略。

#### Scenario: 导入普通文本歌词

- **WHEN** 用户导入一个包含多行文本的 txt 文件
- **THEN** 应用按换行生成与文件顺序一致的歌词行，并显示第一行为当前行

#### Scenario: 歌词文件无法解码

- **WHEN** 导入的文本文件无法按 UTF-8 解码
- **THEN** 应用显示导入失败提示，并保持当前歌词不变

#### Scenario: 歌词为空

- **WHEN** 导入的文本文件只包含空白字符
- **THEN** 应用提示没有可用歌词行，并保持当前歌词不变

### Requirement: 替换当前会话内容

导入新的音频或新的歌词时，应用 MUST 替换对应的旧内容而不是并存。替换音频 MUST 清空已有歌词时间并重置播放位置；替换歌词 MUST 保留当前音轨，但清空已有时间并回到第一行。

#### Scenario: 用新音频替换当前音频

- **WHEN** 已加载音频与歌词后，用户导入新的音频文件
- **THEN** 当前音轨被替换，播放位置回到开头，已有歌词时间被清空

#### Scenario: 用新歌词替换当前歌词

- **WHEN** 已加载音频与部分打点后，用户导入新的歌词文件
- **THEN** 当前音轨保留，歌词行被替换，已有时间被清空，当前行回到第一行

### Requirement: 替换前确认未导出的打点

当当前会话存在已记录但尚未导出成功的时间时，应用 MUST 在执行替换前要求用户确认；用户取消时 MUST 保持当前会话不变。

#### Scenario: 用户取消替换

- **WHEN** 存在未导出的打点，用户导入新文件并在确认提示中选择取消
- **THEN** 应用不加载新文件，当前音轨、歌词与时间全部保持不变
