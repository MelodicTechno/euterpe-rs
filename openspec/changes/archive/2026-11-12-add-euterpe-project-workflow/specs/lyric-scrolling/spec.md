# Spec Delta

## ADDED Requirements

### Requirement: 预览开头居中第一行歌词

预览模式下，当播放位置早于所有已完成行的开始时间时，应用 MUST 将歌词列表第一行滚动到可视区域中央。该状态 MUST NOT 高亮任何歌词行。播放位置从其他位置回到所有时间戳之前时，应用 MUST 再次执行该居中。

#### Scenario: 进入预览时尚未到第一个时间戳
- **WHEN** 用户在有已完成打点的情况下进入预览，且当前播放位置早于所有已完成行的开始时间
- **THEN** 歌词列表自动滚动到第一行并使其位于可视区域中央，且没有行被高亮

#### Scenario: 从后面跳回开头
- **WHEN** 预览中用户把播放位置跳到所有已完成行开始时间之前
- **THEN** 歌词列表再次把第一行滚动到可视区域中央，且取消原有高亮

#### Scenario: 播放进入第一个时间戳
- **WHEN** 播放位置到达最早一条已完成行的开始时间
- **THEN** 应用按既有规则高亮并居中该行，不再停留在第一行
