# Spec Delta

## Purpose

提供白色、极扁平、低饱和蓝的界面主题，让应用看起来像专业音频工具的安静工作区，而不是带装饰的网页界面。

## ADDED Requirements

### Requirement: 浅色扁平主题

主界面 MUST 使用白色或浅灰背景、深色文字和低饱和蓝强调色。面板与控件 MUST 通过细边框和留白区分，MUST NOT 使用渐变、阴影、模糊或大面积圆角。播放器、歌词列表、预览、对话框、提示与底部切换 MUST 使用一致的浅色扁平视觉语言。

#### Scenario: 查看主界面
- **WHEN** 应用显示歌词或预览
- **THEN** 背景为白色或浅灰，面板之间以细边框分隔，没有渐变、阴影或模糊

#### Scenario: 查看主操作按钮
- **WHEN** 用户查看播放、确认或当前行等强调元素
- **THEN** 强调色为低饱和蓝，而不是高饱和绿色

#### Scenario: 查看状态与错误
- **WHEN** 歌词处于未打点、已开始、已完成或错误状态
- **THEN** 状态颜色采用同一套低饱和配色，并保持文字可读

### Requirement: 浅色滚动条与文本选区

歌词视窗的滚动条 MUST 使用浅灰轨道与滑块；文本选区 MUST 使用低饱和蓝或浅蓝灰色。滚动条与选区 MUST 在白色背景上仍可辨认。

#### Scenario: 滚动歌词列表
- **WHEN** 歌词行数超出可视区域
- **THEN** 右侧滚动条以浅灰色显示，滑块清晰但不过分抢眼

#### Scenario: 选择时间输入框文本
- **WHEN** 用户在时间输入框中选中文本
- **THEN** 选区显示为低饱和蓝或浅蓝灰色

### Requirement: 移除装饰性图标

界面 MUST NOT 显示音符等装饰性图标。播放与暂停等功能性符号可以保留。空状态 MUST 使用文字与扁平留白表达，而不是装饰图形。

#### Scenario: 查看空状态
- **WHEN** 尚未导入任何文件
- **THEN** 空状态只显示文字说明与拖拽区域，不显示音符图标

#### Scenario: 查看播放器
- **WHEN** 音频已加载
- **THEN** 播放器仍显示播放或暂停功能符号，但不显示装饰性图标
