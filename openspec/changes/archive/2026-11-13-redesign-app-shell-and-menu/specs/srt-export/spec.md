# Spec Delta

## MODIFIED Requirements

### Requirement: 导出反馈与导出状态

导出成功后应用 MUST NOT 显示成功通知；只有导出校验失败或写入失败时才显示错误提示。导出 MUST NOT 改变窗口标题中的未保存 `*` 标记，导出成功不会替代保存 `.eusrt` 工程，也不会绕开未保存修改的替换确认。

#### Scenario: 导出成功
- **WHEN** 文件写入成功
- **THEN** 应用不显示成功通知，窗口标题中的工程文件名与 `*` 标记保持不变

#### Scenario: 导出后再导入
- **WHEN** 当前会话有未保存到工程的修改，用户导出 SRT 后导入新文件
- **THEN** 应用仍提示存在未保存修改，要求确认后才替换

#### Scenario: 保存工程后导入
- **WHEN** 当前会话已保存到工程，用户导入新文件
- **THEN** 应用直接执行替换，不弹出未保存确认
