# Spec Delta

## MODIFIED Requirements

### Requirement: 空格记录歌词开始时间

音频正在播放且存在当前行时，用户第一次按空格，应用 MUST 以当前播放位置作为该行的开始时间，并把该行标记为已开始。条件不满足时 MUST 静默无操作。

#### Scenario: 记录当前行开始时间
- **WHEN** 音频正在播放，当前行尚未打点，用户按下空格
- **THEN** 应用把当前播放位置记录为该行开始时间，该行状态变为已开始

#### Scenario: 尚未播放时按空格
- **WHEN** 音频处于暂停状态，用户按下空格
- **THEN** 应用不记录任何时间，也不显示通知

#### Scenario: 没有可打点的当前行
- **WHEN** 所有歌词行都已完成打点，用户按下空格
- **THEN** 应用不新增或修改任何行的时间，也不显示通知

### Requirement: 空格记录结束时间并推进

当前行已记录开始时间时，用户再次按空格，应用 MUST 以当前播放位置作为该行结束时间，将该行标记为已完成，并把下一未完成行设为当前行。

#### Scenario: 完成一行并推进到下一行
- **WHEN** 当前行已记录开始时间且音频正在播放，用户按下空格
- **THEN** 应用记录结束时间，该行状态变为已完成，下一行成为当前行

#### Scenario: 完成最后一行
- **WHEN** 最后一行已记录开始时间，用户在播放中按下空格
- **THEN** 该行状态变为已完成，不显示通知

#### Scenario: 结束时间早于开始时间
- **WHEN** 用户按下的第二次空格对应的播放位置不晚于该行开始时间
- **THEN** 应用不把该行标记为已完成，并提示结束时间必须晚于开始时间

### Requirement: O 键回滚

用户按下 O 键时，应用 MUST 撤销最近一次打点或手动时间修改，恢复该行此前的状态与时间，并在有对应开始时间时把播放位置跳转到该行开始时间。连续按 O MUST 能沿历史逐步回退。没有可回滚内容时 MUST 静默无操作。

#### Scenario: 回滚刚完成的一行
- **WHEN** 用户刚完成一行打点并按下 O
- **THEN** 该行恢复为未打点或仅开始的状态，当前行回到该行，播放位置跳到该行开始时间

#### Scenario: 回滚手动修改
- **WHEN** 用户手动修改某行时间后按下 O
- **THEN** 该行时间恢复为修改前的值，其他行不受影响

#### Scenario: 没有可回滚的修改
- **WHEN** 当前会话尚无可回滚的打点或修改，用户按下 O
- **THEN** 应用不改变任何时间，也不显示通知

### Requirement: R 键清空当前行时间戳

编辑模式下，用户按下 R 时，应用 MUST 清空当前行的开始与结束时间，使该行回到未打点状态。该清空 MUST 记录为一次可回滚的修改，按 O 能恢复清空前的两个时间。当前行没有时间或没有当前行时，应用 MUST NOT 修改任何数据，也不显示通知。预览模式下 R MUST 不产生作用。

#### Scenario: 清空已完成的当前行
- **WHEN** 编辑模式下当前行已有开始与结束时间，用户按下 R
- **THEN** 该行开始与结束时间被清空，状态显示为未打点

#### Scenario: 清空只有开始时间的当前行
- **WHEN** 编辑模式下当前行只记录了开始时间，用户按下 R
- **THEN** 该行开始时间也被清空

#### Scenario: 用 O 撤销清空
- **WHEN** 用户刚用 R 清空某行时间后按下 O
- **THEN** 该行恢复清空前的开始与结束时间，当前行回到该行，播放位置跳到该行开始时间

#### Scenario: 当前行本来没有时间
- **WHEN** 编辑模式下当前行尚未打点，用户按下 R
- **THEN** 应用不改变任何数据，也不显示通知

#### Scenario: 预览模式按 R
- **WHEN** 应用处于预览模式，用户按下 R
- **THEN** 当前歌词与时间不发生变化

### Requirement: 快捷键提示包含清空操作

Settings 菜单中的 Keyboard Shortcuts 帮助 MUST 列出 R 用于清空当前行时间戳，并同时说明空格、P、O 的用途。

#### Scenario: 查看快捷键提示
- **WHEN** 用户通过 Settings > Keyboard Shortcuts 打开快捷键帮助
- **THEN** 帮助中同时包含空格、P、O 与 R 的用途
