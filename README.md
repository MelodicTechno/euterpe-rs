# Euterpe · 歌词打轴器

一个用 Tauri 2 + React + TypeScript + Tailwind CSS 构建的本地桌面小工具：导入歌曲和纯文本歌词，一边播放一边按空格给每行歌词打上开始 / 结束时间，最后导出标准 SRT 字幕；也可以把未完成的打点保存为 `.eusrt` 工程，之后再继续编辑。

## 功能

- 原生 `File / Settings / Help` 菜单：导入、保存、另存为、导出、退出、快捷键帮助与关于
- 窗口标题显示当前工程文件名；存在未保存修改时在文件名后追加 `*`
- 保存 / 打开 `.eusrt` 工程：记录歌词、时间、音频路径与当前行
- 工程音频被移动或删除时仍恢复歌词与时间，之后重新导入音频不会清空时间
- 空格打点、P 播放/暂停、O 回滚、R 清空当前行时间
- 预览模式：歌词随播放滚动并高亮当前行；播放位置早于所有时间戳时居中第一行
- 底部只保留“预览 / 返回编辑”切换，没有可预览内容时禁用
- 浅色极扁平界面：白色/浅灰背景、细边框、低饱和蓝强调色，无渐变、阴影和大圆角
- 仅保留错误与警告提示；成功操作不弹 Toast
- 禁用 WebView 默认右键菜单

## 环境要求

- Windows 优先（其他桌面平台可自行验证）
- Node.js 20.19+ / 22.12+
- Rust 稳定版与 MSVC 构建工具
- WebView2 Runtime（Windows 10/11 通常已内置）

## 开发

```bash
npm install
npm run tauri dev
```

只开发前端界面时可以运行 `npm run dev`，但原生菜单、文件选择、拖拽导入和工程保存/导出需要 Tauri 运行时。


## 使用流程

1. 通过 `File > Import` 或把文件拖入窗口导入。可以同时导入一个音频与一个歌词文件；`.eusrt` 工程需要单独导入。
2. 按 P 或点击播放按钮开始播放。
3. 听到某行歌词开始唱时按空格，记录开始时间；该行唱完时再按空格，记录结束时间并自动进入下一行。
4. 打错了：
   - 按 O 回滚最近一次操作，播放位置会跳到受影响行的开始时间；
   - 选中某行后按 R 清空该行时间；
   - 或直接在行右侧的时间输入框里修改，支持 `HH:MM:SS,mmm` 与 `MM:SS.mmm` 格式。
5. 通过 `File > Save` 保存工程：没有路径时等同 Save As，`File > Save As` 始终选择新路径。窗口标题中的 `*` 在保存后消失。
6. 点击底部“预览”检查歌词与歌曲是否对齐；没有已完成行时该按钮不可用。点击“返回编辑”回到打点界面。
7. 通过 `File > Export` 导出 SRT。只导出已完成打点的行，默认文件名为音频文件名加 `.srt`。

## 菜单与快捷键

| 菜单 | 项目 | 快捷键 |
| --- | --- | --- |
| File | Import | Ctrl+O |
| File | Save | Ctrl+S |
| File | Save As | Ctrl+Shift+S |
| File | Export | Ctrl+E |
| File | Exit | — |
| Settings | Keyboard Shortcuts | — |
| Help | About Euterpe | — |

| 按键 | 作用 |
| --- | --- |
| 空格 | 记录当前行开始 / 结束时间 |
| P | 播放 / 暂停 |
| O | 回滚最近一次打点或时间修改 |
| R | 清空当前行的开始 / 结束时间 |

快捷键在歌词时间输入框内会自动让位给文本输入。

## 界面说明

- 界面内不再显示产品名、工程名、快捷键提示或导入按钮；工程身份只显示在窗口标题栏。
- 底部只有“预览 / 返回编辑”切换，不显示保存、导出或完成计数。
- 成功操作保持安静；文件错误、工程无效、导出失败等仍会显示可关闭的提示。
- 右键菜单被全局禁用，包括时间输入框。

## 项目结构

```text
src/
  App.tsx                    # 会话编排、菜单命令、窗口标题与壳层
  components/                # 播放器、歌词列表、预览、信息对话框、提示
  hooks/                     # 音频播放、拖拽、快捷键、原生菜单、窗口标题
  ipc/files.ts               # Tauri 命令与对话框封装
  lib/                       # 时间、歌词、SRT、工程格式、导入分类等纯函数
  state/                     # 会话 reducer、selector 与类型
src-tauri/
  src/commands.rs            # 读取文件、原子写入
  src/lib.rs                 # Tauri 命令注册
  capabilities/default.json  # 窗口标题与关闭权限
  tauri.conf.json
  icons/                     # 极简单色图标集
```

## 已知边界

- `.eusrt` 只记录音频路径，不内嵌音频；音频被移动后需要重新导入，但歌词与时间会保留。
- 通过 File > Exit 或关闭窗口退出时不会拦截未保存修改；请留意窗口标题中的 `*`。
- 原生菜单只在 Tauri 桌面环境出现；浏览器开发模式仍可拖拽导入，但没有菜单命令。
- 右键菜单被全局禁用，因此输入框也不提供右键复制/粘贴；键盘快捷键仍可用。
- 打点时间取按键瞬间的播放位置，属于人工听感时间，不追求波形级精度。
- 不支持 LRC 导入、波形图、自动对齐和视频字幕。
