# SRT Tool · 歌词打轴器

一个用 Tauri 2 + React + TypeScript + Tailwind CSS 构建的本地桌面小工具：导入歌曲和纯文本歌词，一边播放一边按空格给每行歌词打上开始 / 结束时间，最后导出标准 SRT 字幕。

## 功能

- 拖拽或通过文件选择器导入 mp3 / wav 音频与 UTF-8 txt 歌词
- 拖入新音频或新歌词时替换当前内容；存在未导出的时间时先确认
- 播放 / 暂停、拖动进度、播放结束自动停止（不循环）
- 空格打点：第一次记录当前行开始时间，第二次记录结束时间并自动切到下一行
- 点击任意行可重新打点，直接编辑开始 / 结束时间可手动微调
- O 键回滚最近一次打点或时间修改，并跳回该行开始时间
- 预览模式：歌词随播放滚动并高亮当前行
- 导出符合 SRT 规范的文件（UTF-8、CRLF、毫秒时间码）

## 环境要求

- Windows 优先（其他桌面平台可自行验证）
- Node.js 20.19+ / 22.12+
- Rust 稳定版与 MSVC 构建工具
- WebView2 Runtime（Windows 10/11 通常已内置）

```

```

## 使用流程

1. 启动应用，点击「选择文件」或把文件拖进窗口。需要同时选择 / 拖入一个音频和一个歌词文件；也可以分两次导入。
2. 按 P 或点击播放按钮开始播放。
3. 听到某行歌词开始唱时按空格，记录开始时间；该行唱完时再按空格，记录结束时间并自动进入下一行。
4. 打错了：
   - 按 O 回滚最近一次操作，播放位置会跳到受影响行的开始时间；
   - 或直接在行右侧的时间输入框里修改，支持 `HH:MM:SS,mmm` 与 `MM:SS.mmm`。
5. 点击「预览」检查歌词与歌曲是否对齐，预览中可继续播放 / 暂停 / 拖动进度，点击「返回编辑」回到打点界面。
6. 点击「导出 SRT」。只导出已完成打点的行，默认文件名为音频文件名加 `.srt`。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| 空格 | 记录当前行开始 / 结束时间 |
| P | 播放 / 暂停 |
| O | 回滚最近一次打点或时间修改 |

快捷键在歌词时间输入框内会自动让位给文本输入。

## 项目结构

```text
src/
  App.tsx                    # 会话编排、导入、快捷键与视图切换
  components/                # 播放器、歌词列表、预览、导出、提示
  hooks/                     # 音频播放、拖拽、快捷键
  ipc/files.ts               # Tauri 命令与对话框封装
  lib/                       # 时间、歌词、SRT、导入分类等纯函数
  state/                     # 会话 reducer、selector 与类型
src-tauri/
  src/commands.rs            # 读取文件、原子写入
  src/lib.rs                 # Tauri 命令注册
  tauri.conf.json
```

## 已知边界

- 会话只保存在内存中，关闭应用后不会自动恢复；请在关闭前导出。
- 打点时间取按键瞬间的播放位置，属于人工听感时间，不追求波形级精度。
- 不支持 LRC 导入、波形图、自动对齐和视频字幕。
